# Decisão de identidade visual — restaurar fotografias anteriores

**Data:** 10/10/2026. **Situação:** aplicada localmente; não publicada.

O usuário rejeitou a substituição fotográfica de Instagram feita após a V3.2, preferindo exatamente as três imagens que já estavam no site.

Foram restaurados, byte a byte, da V3.2 anterior:

- `site/assets/img/rodrigo-hero-v2.webp`
- `site/assets/img/rodrigo-mobile-v2.webp`
- `site/assets/img/rodrigo-perfil-v2.webp`
- `site/assets/css/premium.css`
- `site/index.html`
- `site/sobre.html`

Nenhum retrato foi gerado, retocado ou recriado. Os arquivos de imagem originais permanecem inalterados. Nenhuma mudança foi feita no GitHub/Netlify.

## Orientação futura

Manter o visual anterior escolhido pelo usuário. Não substituir fotografias com material dos ZIPs do Instagram sem novo pedido expresso. A opção pela estética original não equivale à certificação de autenticidade fotográfica.
