# Design system RA

## Marca
Usar apenas os arquivos autorizados em `site/assets/img/`. Não criar novo monograma nem marca OAB/Meta. Separar fotografias editoriais das fotos documentais reais.

## Cores de referência (não alterar automaticamente produção)
| Token | Referência | Uso |
|---|---|---|
| profundo | `#08151A` | cabeçalhos e hero |
| petróleo | `#132730` | cartões escuros |
| dourado | `#BDA57F` | detalhes, nunca texto de baixo contraste |
| marfim | `#F2EEE6` | seções de leitura |
| verde | `#457F7A` | detalhes funcionais |

## Tipografia
Cormorant Garamond (títulos) e DM Sans (texto). CSS existente distribuído em arquivos temáticos; evitar regras globais conflitantes. Proporções: corpo 1rem ou maior; botões alvo mínimo 44 px; foco visível; não depender de cor apenas. Redução de movimento via `prefers-reduced-motion`.
